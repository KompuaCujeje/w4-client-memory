# w4-client-memory — CRM «Северный мост», которая ведёт себя сама

Неделя 4 хакатона AI Mindset. Руководитель кидает в бота или на сайт встречи, письма, переписку, голосовые, новости
и старую таблицу — система сама раскладывает их по трём реестрам (организации, люди, проекты), у каждого факта
ссылка на событие-источник, вики клиента переписывается после каждого события, есть справка к встрече и ответы на вопросы.

## Как пользоваться

**Telegram-бот `@KitchenSeverMostBot`**
- файл события (.md/.txt, экспорт Telegram, голосовая .mp3/.ogg, таблица .xlsx) или длинный текст — новое событие;
- голосовое сообщение — событие или вопрос, бот поймёт сам;
- вопрос текстом — ответ до трёх предложений со ссылками на события;
- `/org Терра` — карточка, `/brief Терра` — справка к встрече, `/stale` — протухшие сделки и риски, `/funnel` — воронка и менеджеры.

**Сайт** — сводка, организации / люди / сделки с поиском и фильтрами, карточка клиента (сделки, вики с версиями,
факты по источникам, противоречия, лента событий), воронка и менеджеры, все события, «Спросить», загрузка событий.

## Правила (из словаря кейса)

- **Глубина источника:** расшифровка → письмо → переписка → голосовая → записка. Факт только из голосовой или записки — «не подтверждено». При споре в тот же день побеждает более глубокий источник, расхождение видно в карточке.
- **Живой контакт:** встреча, звонок, письмо, переписка с клиентом или документ от него. Внутренняя переписка, новость и голосовая о той же встрече — не новый контакт.
- **Протухла:** открытая сделка (знакомство — согласование) без живого контакта больше 42 дней на дату последнего загруженного события.
- **Дубли таблицы:** одна организация + один продукт = одна сделка, считается за тем, кто завёл первым. Написания вроде «ООО «Ритейл-Групп»» и «Ритейл Групп» — одна организация.
- **Воронка:** лид дошёл до этапа, если у этапа или более позднего стоит дата или текущий этап не ниже; закрытый — до последнего этапа с датой.
- **Кто хуже:** больше открытых сделок без контакта > 42 дней; при равенстве — больше пропущенных дат этапов на сделку.

## Устройство

Python 3.12, FastAPI, SQLAlchemy (Postgres на Render, SQLite локально), ИИ — OpenAI-совместимый API через ProxyAPI
(разбор событий, вики, справки, ответы, распознавание голоса). События разбираются строго по одному, в порядке поступления.

```
app/main.py       точка входа
app/ingest.py     приём события → разбор ИИ → реестры, факты, противоречия, вики
app/table.py      старая таблица без ИИ: дубли, этапы, бюджеты
app/analytics.py  последний контакт, протухшие, риски, воронка, менеджеры
app/qa.py         ответы на вопросы и справка к встрече
app/bot.py        Telegram (вебхук)
app/web.py        сайт
app/prompts.py    задания для ИИ
```

## Запуск

На Render: **New → Blueprint** → этот репозиторий. Render создаст базу и сервис по `render.yaml` и спросит три значения:
`LLM_API_KEY` (ключ ProxyAPI), `TELEGRAM_BOT_TOKEN` (от @BotFather), `RESET_CODE` (слово для очистки базы).
Проверка — страница `/health`.

Локально:

```bash
pip install -r requirements.txt
LLM_API_KEY=... TELEGRAM_BOT_TOKEN=... uvicorn app.main:app --reload
```

Необязательные переменные: `LLM_BASE_URL` (по умолчанию `https://api.proxyapi.ru/openai/v1`), `LLM_MODEL` (`gpt-4.1`),
`LLM_MODEL_FAST` (`gpt-4.1-mini`), `STT_MODEL` (`whisper-1`), `PUBLIC_URL`.

Секретов в репозитории нет: ключи живут только в настройках Render.
